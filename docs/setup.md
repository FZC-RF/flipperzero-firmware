# FZC-RF Dev Setup
1. Install dependencies: `winget install Git.Git Kitware.CMake Python.Python.3`
2. Install arm-none-eabi-gcc: Download from https://developer.arm.com/downloads/-/gnu-rm
3. Clone repo: `git clone https://github.com/FZC-RF/flipperzero-firmware`
4. Install qFlipper: https://flipperzero.one/update
5. Build: `.\fbt`
