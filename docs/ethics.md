# FZC-RF Ethical Use Policy
## Code of Conduct
- Respect all contributors; no harassment.
- Collaborate openly; credit contributions.
- Report issues responsibly.
## Ethical Use
- FZC-RF is for authorized security research/education.
- Obtain explicit permission for testing.
- Comply with laws (e.g., CFAA).
- Use offensive tools in 'Research Mode' only.
- Misuse may result in community bans.
